あなたはReplitのAIソフトウェアエンジニアです。以下の要件を満たす「物流会社向け・成長型Webサイト（LP＋ブログ＋計測＋AI SEO PDCA）」を、Replit上で動く形でフル実装してください。私はこのままデプロイして運用したいです。コピペで動く完成物を出してください。

# 目的（優先順位）
1) 荷主獲得（最優先：問い合わせ/見積もり）
2) 求人獲得（応募/エントリー）
3) 協力会社獲得（提携/登録）

# 必須機能一覧
A. LP/サイト本体（レスポンシブ）
- トップ（荷主向けLP）：信頼/現場力/対応力を訴求し、CTAを強く（問い合わせ/見積もり）
- 採用ページ：職種・魅力・FAQ・応募導線
- 協力会社ページ：募集要件・メリット・登録導線
- ブログ（SEO記事）：カテゴリ、タグ、検索、関連記事、目次、シェアボタン
- お問い合わせフォーム：荷主/求人/協力会社で分岐（フォーム項目も変える）
- 会社情報ページ：代表メッセージ/理念/会社概要/アクセス/認証（あれば）
- 共通：固定ヘッダー、スムーズスクロール、フッター、CTA帯

B. 計測（Analytics/ PV / クリック/閲覧箇所/都道府県）
- GA4導入（ページビュー、イベント計測：CTAクリック、フォーム送信、電話タップ、LINE/メールクリック）
- Microsoft Clarity導入（ヒートマップ：どこ見た/どこクリック/スクロール/録画）
- 都道府県別の閲覧（GA4の地域 + 参照用にIPベース推定も可能なら実装。ただし精度は参考レベルでUIに「推定」と明記）
- 管理画面で「PV/イベント/都道府県/人気ページ/離脱の多いページ」を見える化（最低限のダッシュボード）

C. SEO記事AI自動生成（※Googleのアルゴリズムそのものを“学習”ではなく、Search Consoleの実データに基づくPDCAとして実装）
- 管理画面で「キーワード候補」を登録できる
- AIが記事を生成（OpenAI API使用）。生成時に以下を必ず満たす：
  - 検索意図に沿う構造（結論→理由→具体例→FAQ→まとめ）
  - E-E-A-Tを意識（一次情報/現場視点/注意事項/免責）
  - タイトル、メタディスクリプション、見出し（H2/H3）、FAQ、構造化データ（FAQ/Article）を自動生成
  - 内部リンク候補（荷主LP/採用/協力会社/関連ブログ）を自動提案
- 記事は「下書き→公開」のワークフロー（公開ボタン）
- sitemap.xml / robots.txt / RSS / OG画像対応
- 画像は最初はプレースホルダーでOK（後から差し替え可能な設計）

D. SEO PDCA（Search Console連携）
- Google Search Console APIを使って、ページ別/クエリ別の「表示回数、クリック数、CTR、平均掲載順位」を定期取得しDBへ保存
- 管理画面で「伸びている記事/落ちている記事」を判定し表示
- 落ちている記事はAIが原因仮説と改善案を出す（例：検索意図ズレ、見出し不足、FAQ不足、内部リンク不足、タイトル弱い）
- 「改善案を反映してリライト案生成」ボタンを実装（AIで改稿→下書き保存→公開）

# 技術要件（Replitで動くことが最優先）
- フレームワーク：Next.js（App Router） + TypeScript + Tailwind CSS
- DB：SQLite（Prisma）でOK（Replitに最適）。後でPostgresに移行しやすい設計にする
- 認証：管理画面は簡易でOK（ID/PWを環境変数に置くBasic Authまたはシンプルなログイン）
- スケジューリング：ReplitのCron相当が無ければ「手動実行ボタン＋サーバー起動時の簡易スケジュール」で代替（Search Console定期取得）
- サーバーサイド：API Routesで実装（/api/*）

# 管理画面（/admin）
最低限ほしい画面：
1) ダッシュボード：PV/イベント/CV/都道府県/人気ページ（直近7日/28日切替）
2) 記事管理：一覧（下書き/公開）、新規作成、AI生成、編集、公開、リライト
3) キーワード管理：キーワード登録、狙うターゲット（荷主/求人/協力会社）、優先度
4) Search Console：取得状況、記事別のCTR/順位、改善提案、リライト生成
※GA4データはGA Data APIを使って取得できるなら実装。難しければ「GA4は外部で見る＋サイト内イベントは自前DBでも保持」の二段構えでもOK
※Clarityは埋め込みでOK（ダッシュボードにClarityリンクを表示）

# サイトのコピー（文章トーン）
- 信頼・誠実・現場力・柔軟対応を強く
- 荷主向け：スピード/品質/安心/対応エリア/車格/時間帯
- 求人向け：待遇だけでなく“誇り/成長/安全/仲間”
- 協力会社向け：継続案件/支払い/条件の透明性/長期関係

- モバイルファースト、表示高速（画像最適化）

# 法務/プライバシー（最低限）
